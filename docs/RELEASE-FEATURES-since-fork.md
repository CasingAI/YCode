## 发版亮点（建议写进 Release Notes 的 15 条）

1. Agent 草稿会话独立 git worktree 隔离执行
2. 消息历史编辑：三态回滚、覆盖恢复、半编辑草稿停靠、fork 继承文件变更；运行中编辑重发内部抢占、历史消息可加附件
2b. 命令→模型绑定：自定义命令可绑定模式+模型（frontmatter mode/model 键，插入自动切换）；内置 compact 提供绑定入口、可在设置页指定压缩专用模型（init 跟随默认，goal/plan 不开放）
3. 计划模式成体系：计划落盘收归运行时、一会话多计划、压缩后可找回、计划卡双入口/静默拒绝/自动拒绝、计划目录侧栏
4. 会话时间线：按整轮下发的 turn-window、补页/滚动锚定、按用户轮跳转的 navigator、过程行折叠汇总
5. 工具调用流式增量执行、先输出先起跑，工具卡补耗时徽标与 task-output 卡
6. 局域网远程控制：浏览器/手机直连同一个 Host；Web 端附件全类型上传、URL 路由与会话深链、连接分层与断线重连
7. 供应商与额度：OpenCode 独立分组 + 套餐用量（console JSON API + Workspace 选择）、DeepSeek 余额展示、OpenRouter/MiniMax/OpenCode Zen 三家余额用量、智谱可关闭隔离、Primary 供应商配置
8. 权限轴收敛为计划/只读/完全访问三档，agent-mode 会话模式轴，模型组 model_group 全链路（composer 工具栏模型组展示 + 门面状态接线），composer 权限身份色，自定义命令可绑定模式并自动切换
9. 上下文与压缩：CompactNow / GetContextUsage 内置工具、容量明细（中英文加权、K/M 口径）、总结跟随对话语言
10. Goal 体系：句中 /goal 开跑、作用域着色、拦截规则、迭代间不打扰
11. 错误与重试：错误横幅原地续跑、EPIPE 归入断连自动重试、连通性探测预算
12. 任务管理：任务标题体系与重新生成、归档/取消归档/自动归档跳过有组会话、命令中心可搜已归档
13. 网络与代理：设置页「网络」分区 + 全局代理总开关、按模型选推理代理、MCP 按服务器配代理出口
14. 移动/窄屏：单列 + 覆盖式抽屉、设置抽屉导航、触屏消息操作行常驻
15. 品牌与分发：YCode rebrand、全套新图标、两阶段启动屏、桌面预编译启动、CLI 版本绑定、Coding Plan 付费引导移除

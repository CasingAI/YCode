# Spec: Desktop 关于面板关闭动画

## 目标

关于面板在 macOS 上仍然是系统 sheet：贴在标题栏下方，打开、位置、阴影都由系统负责。点「确定」或按 Escape / Enter 时，**整块面板（含文字、图标、按钮）跟着系统收起动画一起走**，不能先把内容清掉再播空壳，也不能硬切消失。

## 产品规则

- 关于面板复用同一窗口；父窗口变化时才重建。关闭只收起，退出时才真正关掉。
- **三端有父窗口时都挂接并做成 modal。** macOS 上这就是系统 sheet，位置和打开动画交给系统，不要再手动挪窗口。
- macOS 保留系统阴影与系统圆角，不要为了淡出关掉它们。
- 关闭**禁止**先卸页面，也禁止页面自己关窗。页面只发收起信号；文档保持绘制，直到系统动画播完。
- **macOS 关闭不得先把窗口从屏幕上摘掉再收 sheet。** 正确顺序是：窗口还在绘制时通知父窗口结束 sheet，系统带着整块内容收场；动画结束后，再把 Electron 侧可见性同步成已隐藏。
- Windows / Linux 没有这套 sheet 收场，收到信号后直接隐藏。
- 不要再用 CSS 把背板先淡到透明。那会叠成「内容先没，空壳再走」或「先淡再硬切」。
- 每次打开在隐藏期间重载内容，刷新语言与版本。
- 重复触发只生效一次。

## 现状与根因

用户要的是普通 macOS「关于」：点确定，整块跟着系统动画收走。之前几次修复每次只拆掉一层，所以看起来「改了还是一样」。

1. **Electron 对 sheet 的隐藏顺序反了。** 系统会先把窗口从屏幕上摘掉（内容瞬间没了），再播 sheet 收场（空壳滑走）。JavaScript 的隐藏/关闭改不了这两步的先后。
2. **页面自己关窗会卸内容。** 内容层先没了，后面只剩空窗口在动。
3. **CSS 淡出再隐藏会叠两拍。** 背板先透明，再叠系统收场或硬切。
4. **拆掉 sheet、改成独立窗。** 位置和外观都变了；独立窗的隐藏是硬切。用户明确拒绝这条路。

因此 macOS 必须继续做 sheet；关闭时必须在内容还在绘制时结束 sheet，等系统动画结束再同步隐藏。这条路径 Electron 的 JavaScript API 做不到，需要在同一进程里直接通知父窗口结束 sheet。

## 状态所有者与事件顺序

```text
main（窗口生命周期）
  → 复用窗口；有父窗口则挂接并 modal（macOS = sheet）
  → 隐藏期间重载内容
  → sheet 不手动定位；无父窗口时才按内容区贴顶居中
  → 显示 / 聚焦

renderer（只发信号）
  → 点击「确定」/ Escape / Enter
  → 立刻把标题改成收起信号（不淡出、不关页）

main（macOS 关闭时序）
  → 标题信号：拦截默认改标题
  → 窗口仍可见、内容仍在绘制
  → 通知父窗口结束这份 sheet（不先摘窗口）
  → 父窗口收到 sheet 收场结束，或超时兜底
  → 再隐藏，同步 Electron 可见性

main（Windows / Linux）
  → 标题信号后直接隐藏

退出
  → before-quit 放行真正的 close
```

- 窗口实例所有者：关于窗口引用及其父窗口引用。
- 收起信号：页面与主进程共用同一标题约定。
- 收起不可重入：进行中的系统动画不被第二次点击打断。
- 原生辅助只做一件事：对已挂接的 sheet 调用结束 sheet。加载失败或当前不是 sheet 时，退回直接隐藏（硬切），不发明第二套动画。

## 接口与实现边界

- 页面脚本：只发收起信号，不关页、不加关闭淡出态。
- 窗口挂接：有父窗口就挂接并 modal，三端一致。
- 主进程关闭：macOS 走结束 sheet，其它平台直接隐藏。
- 原生辅助：按窗口句柄找到视图所属窗口及其 sheet 父窗口，只结束 sheet。开发态与打包态都从桌面资源目录加载；产物不入库，构建脚本在 macOS 上编译。
- 不新增 preload 或 IPC 通道。

## 验收场景

1. 打开关于：macOS 仍是贴在标题栏下的系统 sheet，位置和打开方式与改动画之前一致。
2. 点击「确定」：整块内容跟着系统收起动画一起走；没有内容先消失、没有空壳再滑、没有硬切。
3. 按 Escape 或 Enter：与点击「确定」一致。
4. 重复打开：复用窗口，语言与版本正确；macOS 仍是 sheet。
5. 连点只生效一次。
6. 应用退出不被拦截。
7. 原生辅助缺失时允许退回直接隐藏，不崩溃。
8. 定向测试与 Lint 通过。

## 负面边界

- 不改关于面板的行高、内容尺寸与文案。
- 不在主进程用窗口透明度做渐出。
- 不再把 macOS 关于面板改成独立窗口来「绕开」sheet。
- 关闭路径不再卸页面。
- 不改图标、版本号取值与上游版本行逻辑。

# 文件树右键文件操作

## 产品规则

- 文件夹右键提供「新建文件」「新建文件夹」「粘贴」；文件和文件夹提供「复制」「剪切」「重命名」「删除」。工作区根目录入口提供新建与粘贴，不允许改名、剪切或删除根目录。
- 保留打开、打开方式、在文件管理器中打开、复制路径等现有动作；不恢复「添加到聊天」，不新增终端或搜索入口。
- 使用现有 Dialog / AlertDialog 交互：新建和改名输入单个名称，不接受路径分隔符、空名称、`.` / `..` 或平台非法名称。新建与改名遇到同名目标失败并保留输入，禁止覆盖。
- 新建文件立即创建空文本文件并在工作台打开；新建目录成功后刷新并展开父目录。取消对话框不产生文件 IO。
- 剪贴板为窗口内单项文件剪贴板，与文本「复制路径」独立；保存操作类型、源工作区身份 / 远程会话、源路径及条目类型，不复制正文。
- 仅支持同一工作区及远程会话内的粘贴，跨工作区粘贴不可用，不回落到本机路径。文件复制读取磁盘内容，包含二进制文件；目录复制递归处理且不跟随符号链接。
- 复制到同目录或遇到同名目标时生成 `name copy.ext`、`name copy 2.ext` 等不冲突名称。移动遇到同名目标失败，不覆盖；移动到原目录为无操作，成功后清空对应剪切剪贴板。复制后保留剪贴板。
- 禁止把目录复制 / 移动到自身或子目录；Host 校验根目录边界、目标存在性与条目类型，UI 的可用状态不能替代校验。
- 删除使用明确的永久删除确认，目录说明包含子项；不冒充系统回收站。删除成功后关闭干净标签，未保存文本转为未命名草稿，保留正文并要求后续另存为，避免重新创建已删除路径。
- 重命名和移动成功后，将同工作区下对应文件及目录子路径的编辑缓冲、所有分屏标签、焦点及待打开意图迁移到新路径；保留未保存正文与已保存基准，不能调用会清除脏态的「已保存」动作。
- 操作失败不改编辑缓冲或草稿；对话框保留输入并显示错误。成功才更新编辑器投影、剪贴板与文件树，再持久化现有编辑会话。
- 执行期间同工作区文件操作不可重复提交，不自动重试变更请求；切换工作区后旧结果只能协调原工作区缓冲，不得打开当前工作区文件或覆盖当前对话框。
- 保存与文件变更共用窗口内同工作区操作准入，保存从读取冲突基准到写盘和更新缓冲期间持有准入。Host 的文件变更请求也串行处理；原生改名在检查目标不存在后执行，不承诺阻止外部进程在检查与系统调用之间创建目标。
- Desktop、Web、手机远控均调用所属工作区文件服务。远程连接未就绪、只读或临时外部目录禁用写操作；保留 `workspaceIdentity?.trim() || workspacePath` 及远程会话隔离。

## 所有者和接口

| 内容                         | 唯一所有者                                |
| ---------------------------- | ----------------------------------------- |
| 命名 / 删除确认表单          | 文件树操作 Hook 与 Dialog                 |
| 单项文件剪贴板及操作中状态   | 窗口内文件树操作 Store；不持久化          |
| 文件系统变更与搜索索引失效   | Host `IFileService.mutateWorkspaceEntry`  |
| 已打开文件、分屏与未保存草稿 | 既有 Files Editor Store；增加变更协调动作 |
| 目录及 Git 状态              | 既有文件树 Hook / watcher，变更后刷新     |

文件服务使用严格类型的变更联合：创建文件、创建目录、改名、删除、复制、移动。请求携带根路径及工作区身份，返回实际路径、原路径、类型及是否发生变更；运行时验证操作与路径，不通过 UI 调用 Node 文件系统或 Shell 命令。

```text
文件树菜单 → 表单 / 剪贴板 → 同工作区操作准入
  → 所属 Host 文件服务 → 校验并修改磁盘 → 失效文件搜索索引
  → Files Editor Store 协调路径 / 删除草稿 → 持久化现有编辑会话
  → 刷新原工作区目录与 Git 状态

Desktop / Web / 手机 → 同一文件服务请求与结果；不改聊天 stream 或 replay 语义
```

## 验收

自动化回归使用临时目录及内存状态，不启动或控制 YCode：

1. 创建文件 / 目录成功；同名、非法名称、根目录操作与越界路径失败且原内容不变。
2. 重命名、剪切移动、二进制复制、递归目录复制、同名副本命名正常；目录自嵌套、移动重名失败。
3. 连续变更串行准入；成功后文件搜索看见新路径，失败不清掉已有内容或剪切状态。
4. 改名及移动后未保存正文、基准、分屏引用与焦点保留；同路径的另一工作区不受影响。
5. 删除干净文件关闭标签；删除含脏文件的目录把脏内容转为未命名草稿；失败不修改 Store。
6. 剪贴板只对相同工作区和远程会话可粘贴；移动只清除本次消费的剪切项，不清掉操作期间新复制的项。

交互 E2E 场景（遵守仓库操作授权规则，未授权时只记录、不执行）：

1. 文件夹和工作区根入口新建文件 / 目录；取消、重名重试、成功打开及刷新展开正常。
2. 文件和目录可改名、复制、剪切、粘贴和确认删除；菜单按目标、连接和执行状态禁用，保留原有打开 / 复制路径入口。
3. 多分屏中改名、移动及删除包含未保存文本的目录，标签、正文、草稿恢复和保存目标正确。
4. Desktop / Web 窄屏、中英文、本地 / 远程工作区使用同一操作语义；断线失败不回落本机，跨工作区粘贴不可用。

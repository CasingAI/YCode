# Spec: 会话产物占用提示

## 目标

让用户在会话产生大量 YCode 管理文件时及时发现占用，并能查看按类别汇总的现场扫描结果。提示本身不显示具体大小；详情由用户主动打开。

## 产品规则

- 一轮实际运行从 `running` 进入任一终态后扫描一次；首次打开已结束的历史会话时补扫一次以恢复横幅。草稿和未进入 `running` 的预热不扫描；中止或错误结束也算一轮结束。
- 当前会话及其所有 `subagent_child` 后代会话的 YCode 管理产物都计入；按现有存储目录归为命令输出、工具产物、子代理 transcript、模型轨迹、沙盒数据和临时缓存。共享日志、共享 SQLite 会话库、用户工作区文件不计入。
- 大小按文件逻辑字节数估算，与存储管理现有口径一致；硬链接或文件系统克隆可能被重复累计，详情弹窗沿用现有估算说明。
- 统计由当前会话绑定的 CLI Host 执行。Host 从自己的配置解析存储根，只接受会话 ID，不接受 renderer 传入的任意路径。持久化会话父子关系用于覆盖尚未驻留内存的子代理；沿 parentID 递归时只接纳 `subagent_child`。
- 完整扫描结果严格大于 50 MiB 时，在会话顶部显示警告色悬浮横幅。横幅不包含占用数值，提供“查看详情”和关闭按钮。
- 关闭状态由 CLI Host 按会话 ID 持久化；后续轮次、重新打开会话、桌面与 Web/远程客户端都不再显示。不同会话（含 fork）独立判断。
- 点击“查看详情”时重新扫描完整范围，展示总占用和各非零类别大小。扫描期间显示加载态；扫描错误明确显示失败/不完整，不以不完整结果判定阈值。
- 已结束的关联后台工作（Bash、子代理或 workflow）从 `running` 变为终态或从快照移除时，再补扫一次；多个工作分别结束时分别触发补扫。普通前台工具更新不触发额外扫描。
- 本地桌面可用现有“存储管理”入口；Web/远程仍可扫描和查看详情。若当前平台没有存储管理能力，详情中的该按钮保留但禁用并说明当前平台不提供此入口。

## 所有者与接口

- **占用数据所有者：** 会话所属 CLI Host。只读 V4 查询按 `sessionId` 返回总字节数、类别明细及扫描完整性；远程身份由现有 workspace connection/lease 路由，不改变 Host owner。
- **关闭状态所有者：** CLI Host 的会话占用提示状态文件，使用原子写入；Renderer 只发出关闭请求，不维护第二份持久真值。
- **短暂 UI 状态所有者：** 当前 `SessionPane`，仅保存当前扫描状态、横幅显示态和详情弹窗开合态。结果按 `sessionId` 校验，切换会话后的迟到响应不更新新会话。
- **查询接口：** `v4/conversation/sessionStorageUsage`，输入仅含 `sessionId`，返回 `totalBytes`、按 `StorageCategoryId` 分类的 bytes/fileCount、`complete` 与局部错误数。
- **关闭接口：** `v4/conversation/dismissStorageWarning`，输入仅含 `sessionId`；会话存在性和工作区路由由 CLI Host 校验。
- **按钮路由：** 复用现有 Settings Storage 入口和平台能力；不把本地 Desktop 扫盘桥误用于远程 Host。

## 状态与时序

```text
CLI Host / conversation snapshot                 SessionPane
          │                                            │
          ├─ running → terminal ──────────────────────▶│
          │                                            ├─ sessionStorageUsage(sessionId)
          │◀───────────────────────────────────────────┤
          ├─ 扫描会话及 subagent 后代                 │ complete && bytes > 50 MiB → 显示 banner
          │                                            │
          ├─ 后台工作 running → terminal/removal ─────▶│ 再发同一只读查询
          │                                            │
          │                         点详情 ────────────┤ 再发现场查询 → 分类明细
          │◀───────────────────────────────────────────┤
          ├─ dismissStorageWarning(sessionId) ◀────────┤ 点叉
          └─ 原子持久化关闭状态 ───────────────────────▶ banner 永久隐藏
```

- V4 请求无状态、按 session ID 授权，桌面 `desktop-continuous` 与 Web/远程 `web-remote-replayable` 都通过当前 Host 查询；不把扫描结果加入 transcript 或 topic replay。
- 查询失败不弹横幅；详情展示可恢复错误。扫描结果只在请求所属会话仍为当前会话时应用。
- 自动扫描允许单飞；扫描过程中再次收到结束事件时标记待补扫，当前扫描结束后再执行一次，避免漏掉后写入的文件。

## 验收场景

1. 轮次结束后，总量 50 MiB 或更少时不显示横幅；严格超过 50 MiB 才显示。
2. 横幅不显示大小；关闭后刷新、切换回来、下一轮结束以及另一个 Web/远程客户端都不再显示。
3. 点详情时执行一次新的完整扫描，列出总量及各类别占用；同一类别文件正确合并，零值类别隐藏。
4. 统计包含当前会话和任意深度的 `subagent_child` 后代；不把普通 fork/side chat 当作子代理。
5. 统计不包含共享日志、共享数据库和工作区项目文件；局部扫描错误不会被伪装成完整结果。
6. 轮次结束时后台工作仍运行；每个工作之后结束时都能触发补扫并更新提示状态。
7. 本地 Desktop 与 Web/远程客户端的扫描都由它们当前连接的 CLI Host 执行，绝不把远程路径交给本地文件系统。
8. Desktop 的“存储管理”按钮打开现有 Storage 分区；缺少该平台能力时按钮禁用并提供说明。
9. 切换会话期间旧扫描迟到返回时，不改变当前会话横幅或详情。

## 验证

- 纯函数测试覆盖阈值、后台工作结束识别、子代理后代筛选、类别汇总与路径排除。
- 协议/Host 测试覆盖 session 授权、持久化关闭状态和远程查询路由。
- 交互使用组件测试覆盖横幅、详情弹窗与关闭行为。遵守仓库 UI 操作限制，不通过 CDP 或桌面 UI 自动化操作正在运行的 YCode。
- 必须执行 `pnpm architecture:check --changed`、`pnpm typecheck` 与 `pnpm lint`。

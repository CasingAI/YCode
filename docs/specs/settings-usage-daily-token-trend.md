# 使用统计：每日 Token 趋势图（总量 / 分模型）

## 背景

原实现只绘制时间范围内 token 总量前 6 名的模型（`slice(0, 6)`），而 tooltip 标题显示当天**全部**模型的合计。当天用量大但 7 天累计排名未进前 6 的模型（例如日常主力 `glm-5.3`）整条折线不可见，也不出现在 tooltip 行中，造成「明明用了一天却查不到」与「标题 6 亿、可见行合计 4.1 亿」的不一致。

## 产品规则

### 模式切换器

- 图表标题行右侧提供模式切换器：`分模型` / `总量`，复用范围页签的 Tabs 样式。
- 默认 `分模型`。切换时间范围（7d / 30d）时保留当前模式；离开使用统计页后重置为默认。

### 分模型模式

- 绘制时间范围内**全部** `totalTokens > 0` 的模型，不截断条数；0 用量模型不画线也不进图例。
- 颜色沿用 6 色循环色板，超出后重复。
- 图例列出全部绘制的模型，自动换行。
- tooltip 标题为「日期 - 当天全部模型合计 tokens」；行为当天 `> 0` 的全部模型。标题合计与行合计自洽（所有有量模型均有折线）。
- Y 轴上限跟随单模型单点峰值（不是各模型之和），避免可见曲线被压扁。

### 总量模式

- 单条折线，值为每天全部模型 token 合计。
- 不显示图例；tooltip 只显示「日期 - 当天合计 tokens」，不重复列出单模型行。
- Y 轴上限跟随全天合计峰值。

### 空状态

- 当前模式的峰值 ≤ 0 时显示 `UsageEmptyState`，与现有行为一致。

## 状态所有者

- `AppUsagePanel` 持有 `chartMode`（React 本地状态，不持久化、不是服务端事实），经 props 传入 `AppUsageDailyModelTrendChart`；图表组件纯展示。
- 数据唯一来源不变：CLI runtime 写入的本地 `model_usage`（协议 `v4/usage/stats`），本改动只动展示层。

## 不变量

1. tooltip 标题中的当天合计 == 当天全部模型 tokens 之和（含与不含折线的模型，值恒等）。
2. 分模型模式下，任何在范围内有量的模型至少出现在一条折线和一个图例项中。
3. 模式切换只改变展示，不改变数据请求与聚合结果。

## 验收场景

1. 构造 8 个 `totalTokens > 0` 的模型：分模型模式折线数、图例数、`chartConfig` 条目均为 8；第 7、8 个模型当天有量时出现在 tooltip 行中。
2. `models` 中含 `totalTokens === 0` 的条目：不产生折线与图例。
3. 某天仅模型 A（排名 8）有量：分模型模式标题合计 == A 的 tokens == 可见行合计。
4. 切到总量模式：仅一条折线；tooltip 仅显示「日期 - 合计」。
5. 切换 7d → 30d：模式选择保留。

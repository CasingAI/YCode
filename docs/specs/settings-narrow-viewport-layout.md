# Spec: 系统设置页的窄视口布局（抽屉导航 + 行堆叠）

## 目标

窄视口下系统设置页（`SettingsPage`，Desktop 与 Web 共用）从「常驻图标栏 + 内容列」切换为「单列内容 + 覆盖式分区导航抽屉」，并把设置行、快捷键表等固定栅格在极窄宽度下堆叠，消除标签被控件挤压成一字一行的问题。宽视口（≥768px）观感逐像素不变。

此前的窄屏处理只有 `max-lg:` 的图标栏压缩：图标栏仍常驻占 68px，且 `SettingsRow` 的控件列固定 192px，375px 视口下标签列只剩约 60px，中文标签与描述被挤成竖排单字。

## 产品规则

### 形态判定

- **断点 768px**，与 `workspace-shell-responsive-layout.md` 同一口径：判定使用 `useIsNarrowViewport()`（`(max-width: 767.98px)`），768px 整宽按宽视口处理，不引入第二套断点。
- 三档呈现：
  - **< 768px（窄视口）**：分区导航收进覆盖抽屉，内容单列占满；
  - **768–1023px**：维持既有 68px 图标栏（`md:grid-cols-[68px_...]`）；
  - **≥ 1024px**：维持既有 268px 完整侧栏（`lg:grid-cols-[268px_...]`）。
- 桌面 Electron 窄窗口与 Web 同等生效，不按平台分支。
- **判定只决定形态，不决定显隐**：抽屉开合是 `isNavDrawerOpen` 一根独立状态轴，初始收起；旋转屏幕/拖拽窗口跨越断点不自动改写用户的开合意图。

### 窄视口：分区导航抽屉

- 抽屉从左侧滑入，覆盖整个设置页，宽度 `min(85vw, 320px)`。
- 展开/收起由 `translate-x` 表达，抽屉宽度不随显隐变化（宽度同时归零会让展开变成挤压动画）；过渡 `duration-200 ease-out`，与工作区抽屉同参数。
- 抽屉自带不透明表面：`bg-background` + 右边框 + 投影；浮在内容之上，缺底色会与下层文字叠印。
- 抽屉展开时渲染遮罩（`bg-black/40`），点击遮罩即收起。
- 层级：遮罩 < 抽屉 < 页内右上角帮助按钮/窗控。设置页内帮助按钮位于右上角，与左侧抽屉无重叠。
- 抽屉内呈现**完整侧栏内容**（返回工作区按钮、分组与分区项带文字标签，非图标态）；`WorkspaceSidebarFooter` 维持 `max-lg:hidden` 不进抽屉，主题/语言/账号仍留在工作区侧栏，不复制第二份入口。
- **导航动作完成后收起抽屉**：点选任一分区、点击返回工作区都先执行原导航语义、随后收起抽屉；收起跟在导航之后，不替代它。
- 顶栏入口：窄视口下设置页顶栏（面包屑行）左侧常驻两个入口——返回工作区（`onBack` 存在时）与分区导航开关（`PanelLeftOpen` 图标）。抽屉打开时入口随页面一起被遮罩盖住，关闭手段是遮罩点击与导航完成，这与工作区「浮层开关常驻」不同：设置页顶栏在面板框内，不再额外抬层级。
- 宽视口下抽屉相关节点不渲染（遮罩）或回退为静态内联列（aside），不产生多余包裹层。

### SettingsRow 行堆叠（< 640px）

- `SettingsRow` 默认栅格从 `grid-cols-[minmax(0,1fr)_192px]` 改为移动优先：**< `sm`（640px）单列堆叠**——标签与描述在上，控件在下、左对齐、允许换行（`flex-wrap`）；≥ `sm` 恢复既有两列右对齐，观感不变。
- `controlLayout: "wide"` 变体同样在 < `sm` 堆叠（`sm:grid-cols-[minmax(0,1fr)_280px]` 不变）。
- 阈值取 `sm` 而非自定义断点：640px 以下内容列（扣除边框与内边距）不足以为 192px 控件列保留可读标签宽度；640–768px 虽仍两列但标签列 ≥ 300px，可读。

### 模型行换行（流式，无断点）

- `ModelRowInput`（`packages/ui/src/settings/model-provider-section/ProviderFormControls.tsx`）行主容器与左侧信息区允许换行（`flex-wrap`）：行宽足够时保持现有单行紧凑布局；行宽不足时操作组（测试/编辑/删除/开关）整体折到第二行右对齐，徽标先折到模型名下一行，模型名保留 `truncate` 不再被压到单字。
- 操作按钮组包一层不拆散的容器，换行后两行保持 `8px` 级紧凑间距；不新增颜色、字号与断点，桌面宽屏观感不变。
- 徽标文案口径（K/M/B）、视觉徽标显隐规则、增删改开关行为不变。

### 快捷键表堆叠（< 640px）

- 表头只保留「命令 / 操作」两列，键位与作用域表头隐藏。
- 数据行改为两行栅格：第一行命令名 + 操作；第二行键位组（占满行宽，键帽序列可换行）+ 作用域文本。≥ `sm` 恢复既有四列。

### 根网格高度口径（`SettingsPage.tsx`）

- 设置页根网格的高度必须与窗口框架的动态视口对齐：使用 `h-dvh`，**禁止 `h-screen`/`100vh`**。
- 原因：外层 `DesktopWindowFrame`（`packages/ui/src/DesktopWindowFrame.tsx`）与 `#root`（`packages/ui/src/styles.css`）都是 `h-dvh` + `overflow:hidden`。手机浏览器上 `100vh` 会把地址栏区域算进高度，根网格比可视区高出一截，超出部分被祖先裁切；滚动容器 `<main>` 的高度从根网格继承，滚到底也只能到达被裁掉的底边，表现为「滚不到底」。
- 桌面 Electron 端 `100vh` 与 `100dvh` 等值，该口径在桌面视觉零变化。

### 不改动项

- `SettingsMasterDetailLayout`（供应商和模型等内层主从）维持 56px 窄栏与 `md:224px` 栅格：其导航承载 dnd-kit 纵向拖拽排序，横向化会破坏排序语义；外层抽屉已把内容列宽度还给详情区。模型组页按 `model-group.md` 的窄屏呈现走：左栏文字组名收为首字入口（`sr-only` 保留组名），详情区行允许换行，不新增断点。
- 各分区的表单、对话框、面包屑投影逻辑不变；本 spec 只覆盖纯呈现层。
- safe-area / `viewport-fit=cover`：仓库 `env(safe-area-inset-*)` 仅用于 toast，`packages/web/index.html` 的 viewport 也没有 `viewport-fit=cover`；手势条遮挡属于另一件事（需改 viewport meta 与多处底部内边距），且它无法解释「能滚但滚不到底」，本次不纳入。

## 验收场景

1. Web 版 375px：常规/外观/网络/浏览器控制/记忆/实验特性分区的每一行标签与描述完整换行，不再出现一字一列竖排；控件堆叠在标签下方。
2. Web 版 375px：顶栏可见返回与导航开关；打开抽屉后分区带文字标签呈现，点选分区后抽屉收起并切换内容。
3. Web 版 375px：快捷键表行内命令名完整、键帽组可换行、作用域可见。
4. Web 版 768px 与 1440px：三档布局与改动前逐像素一致（68px 图标栏 / 268px 侧栏、行两列右对齐、快捷键四列表）。
5. 桌面端（共用组件）≥768px 行为不变；窄窗口下抽屉可用。
6. 纵向滚到底可达：Web 版 375px（地址栏展开状态）把任意长分区滚到底，最后一行完整露出，其下留有底部内边距；地址栏收放前后底部依然可达。
7. `pnpm typecheck` 与 `pnpm lint` 通过。

# 消息编辑态图片移除按钮颜色

## 行为

`ConversationRowView` 的消息编辑态媒体缩略图提供圆形移除按钮。按钮使用主题语义颜色，叉号在已支持的浅色、深色及 Zai 主题下都必须与按钮底色保持清晰对比；非编辑态消息附件展示不受影响。

## 所有者与边界

- 展示由 `ConversationRowView` 中的附件渲染负责；移除行为仍通过现有 `AttachmentRemove` 回调交给消息编辑状态所有者。
- 本修复仅调整编辑态媒体按钮的视觉 token，不改变状态、接口、附件数据或移除时序。
- 按钮前景色必须与其背景所用的语义色配对，不能使用依赖 `--color-primary` 的 `primary-foreground`。

## 验收场景

1. 编辑带图片消息时，悬停图片或键盘聚焦移除按钮，叉号在按钮底色上清晰可见。
2. 使用浅色、深色及 Zai Light / Zai Dark 主题时均遵循主题语义 token。
3. 激活按钮仍调用原有 `onRemove`，不改变附件移除行为。

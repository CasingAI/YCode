# Spec: 工作区外壳底栏「更多」（杂项菜单与远控）

## 目标

侧栏底部的头像 / 「连接使用」行已经不是一级导航：主视图切到「任务 / 文件 / 设置」底栏之后，它只是一份挤在身份条上的杂项菜单，外加一个手机远控图标。本次删掉身份条，把那份菜单和远控收进底栏最后一格「更多」。点开仍是下拉，不切左栏 / 右栏，也不做账号页。

## 产品规则

### 底栏四格

- 左栏最底部导航条四格：任务、文件、设置、更多。
- 任务、文件、设置是外壳主视图（`tasks` | `files` | `settings`），点中切左栏列表和右栏正文。文件细则见 `workspace-files.md`。
- 「更多」不是主视图：没有 `aria-current`，不写 `tabStore` 的主视图投影，不改左栏 / 右栏。点开只弹出下拉。
- 文案复用 `common.more`。顶部一级导航的「更多」（自动化 / 插件市场）不动；两个入口同名、职责不同。

### 菜单内容

顺序固定：

1. 手机远控（仅当前 attachment 提供远控服务时出现；Web / 远程 workspace 不出现这一项，「更多」格子仍在）；Web 在对应位置显示「连接信息」，点击查看当前业务通道与连接状态，见 `web-connection-info.md`。
2. 语言
3. 主题
4. 界面模式
5. 界面缩放（仅桌面）
6. 资源管理器（仅桌面；复用「帮助 → 资源管理器」同一条桌面命令，打开同一个独立窗口）
7. 使用统计（写入用量意图后进设置，不另做正文）
8. 退出（已登录且调用方提供了退出回调）

语言 / 主题 / 界面模式 / 用量仍同时存在于设置页，菜单只是快捷入口。

### 不再有账号「连接」入口

- 「更多」是杂项菜单，只放应用设置与宿主能力入口，不再放账号连接入口：未登录时菜单里不出现账号「连接」，也不留占位。Web 的只读「连接信息」不属于账号连接，不触发登录或重连。
- 理由：首启已无登录墙（见 `startup-first-run-experience.md`），「连接」点开是整屏欢迎页而不是菜单内的对话框，从杂项菜单点进去会突然接管整个窗口；用户要配供应商走设置页，要连账号走命令面板。
- 账号连接能力本身不删：命令面板的「连接 / 登录」命令、运行时凭证失效与退出后重连的欢迎页都保留，OAuth 登录与重登录仍可用。
- 已登录时菜单里的「断开连接」保留：断开是破坏性动作，需要一个显式出口。

### 资源管理器入口

- 资源管理器是桌面独立窗口，Web 端没有该窗口，因此这一项只在桌面端渲染；判定用注入的 `isDesktop`，不用 `IPlatformService` 嗅探（Web 桩也实现了 `executeDesktopCommand`，嗅探会渲染出点了没反应的入口）。
- 入口复用 `DesktopCommandIds.OpenResourceManager`，不新增命令、不新增窗口、不新增通道。窗口单例，已存在时由 Main 聚焦。
- 入口只是导航快捷方式，不持有资源采样状态；采样生命周期仍在 Main。

### 身份条删除

- 不再渲染头像、显示名、「连接使用」、套餐徽标。
- 不要账号页，不要把登录做成常驻身份芯片。

### 远控开启态

- 远控仍由 Host 上的 `IMobileRemoteControlService` 唯一持有；UI 只投影。
- 点「手机远控」打开原对话框，不收起窄屏抽屉。
- `status.enabled` 为真时，「更多」这一格带开启态（沿用原来图标变色的信号）。这是侧栏里唯一的远控状态信号，不再打在独立手机图标上。

### 窄屏抽屉

- 打开「更多」、点远控或 Web「连接信息」，不收起抽屉。
- 点使用统计走现有用量意图 + 进设置；切主视图不收抽屉，规则与 `workspace-shell-primary-tabs.md` 一致。

## 状态所有者与事件顺序

| 状态 | 所有者 | 说明 |
| --- | --- | --- |
| 任务、文件还是设置 | `tabStore` 的主视图投影 | 不变。「更多」不写入。 |
| 「更多」开合 | 下拉内部状态 | 不进 zcode store。 |
| 远控运行时 / 落盘 | `IMobileRemoteControlService` | UI 只投影 hook 快照。 |
| 语言 / 主题 / 界面模式 / 缩放 | 既有偏好与桌面命令 | 菜单只发命令，不另存一份。 |
| 资源管理器窗口 | Main 的单例窗口 | 菜单只发 `OpenResourceManager` 命令，不持有窗口与采样状态。 |

```
点「更多」
  → 下拉开合（Radix；Esc / 点外部 / 选中即关）
  → 选「手机远控」
    → 开原对话框；抽屉不收
    → start/stop/resetToken 仍回落 Host
  → 选「使用统计」
    → 写入用量意图 + 进设置主视图
  → 选「资源管理器」（仅桌面）
    → 发 `OpenResourceManager` 桌面命令 → Main 打开/聚焦单例窗口
  → 选语言 / 主题 / 界面模式 / 缩放 / 退出
    → 走既有回调或桌面缩放命令
```

## 负面边界

- 「更多」不得升级成 `WorkspaceShellPrimaryView`。第三档是文件，见 `workspace-files.md`。
- 不把「更多」做成和设置一样的左右栏页面。
- 不把语言 / 主题从设置页搬走。
- 不改登录协议、远控 Host、设置分区目录、顶部「更多」。
- 不为手机远控、relay、Host attachment 引入新路由。

## 验收场景

1. 宽屏有项目：底栏四格；头像行消失；点「更多」出菜单；点任务 / 文件 / 设置仍切主视图。
2. 远控可用时菜单第一项能打开原对话框；开启后「更多」带开启态。Web 与远程 workspace 无远控项，「更多」仍在。
3. 未登录菜单没有「连接」项；已登录有退出。无项目设置页同样有「更多」。手动连接账号走命令面板的「连接 / 登录」命令。
4. 窄屏抽屉：开菜单或点远控不关抽屉。
5. 桌面端「更多」菜单有「资源管理器」，点击打开（或聚焦）资源管理器窗口；Web 端菜单没有这一项。
6. `pnpm typecheck`、`pnpm lint`、`pnpm architecture:check --changed` 通过。

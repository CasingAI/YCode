# Spec: Bare Worker（可切档的平行工人）

Bare 父派出的内置子代理类型 **Worker**（内部值 `Worker`，中文显示名 **工人**）。调用面仍是派出 / 续跑；内在是一条与主会话同构的通用会话：完整工具面、Ask / Agent 两档、系统说明不写死工种。档位由 Bare 秘书在两次前台执行之间切换，切的是这条子会话自己的档，不改父档。

本文件是 Worker 的权威规格。父会话四档、秘书白名单、子权限等级门仍以 [`bare-mode.md`](./bare-mode.md) 为准；本文件只写 Worker 对那份规格的增量，以及它如何替换 Bare 下的 Explore / 通用默认路径。

## 目标

- 同一条「先查后改」的任务线可以留在 **同一条 Worker 会话** 里，调查阶段付过的前缀在动手阶段继续命中，不再因为换 Explore → 通用而整段作废。
- Bare 秘书眼里它仍是子代理：前台加入父回合，用稳定身份续跑，答复回到父模型。
- 工人眼里它是通用代理：开场系统说明不宣布「你是查阅专家」或「你是通用工人」；行为只跟当前档位标签走。

## 问题

传统 Agent 一把梭时，调查和改动发生在同一条会话，系统说明、工具表、已读文件都还在前缀里。Bare 现行默认把调查派给 Explore、改动派给通用：两条生命、两套工具面、两份系统说明，缓存无法接续；秘书只拿到摘要，动手方往往还要再读一遍。

根因不是「子代理不能续跑」（同一身份续跑本来就能保住缓存），而是 **工种一变就新开一条写死身份的会话**。

## 状态所有者

真值仍是各 runtime 自己的 `mode`。Worker 的档位在 **子 runtime** 上，不在父 runtime 上。父是 Bare；子只允许 Ask / Agent。

```text
Bare 父派出 Worker（可选带档，缺省 Ask）
  → 子 runtime 写入自己的 mode，工具表从第一天固定
  → 前台跑到终态，父工具返回（含身份与当前档）
  → 秘书续跑（可选带下一档；缺省保持）
  → 仅终态续跑路径把新档写入子 runtime，再跑下一轮
  → 子快照投影当前档；侧栏状态条只读展示
```

切档写入点只有子会话既有的档位写入路径，经子 runtime 落盘、改内存、发子会话的档位变更事件。禁止走父会话的切档口，禁止把子档写进父配置。正在跑的一轮（转向 / 入队）不得改档。

PermissionService 实例可在父子间共享；判定只读本次调用的 `context.mode`。漏把父 Bare 当成子档、或把子 Ask 当成父档，都是缺陷。

## 产品规则

### 类型与可见性

- 内置类型名 **Worker**，显示名英文 Worker、中文工人。设置里可作为内置项出现，并标明仅 Bare 可派；Explore / 通用在设置里仍保留给其它档使用。
- 三个内置类型的**内部身份永远是英文名**（`general-purpose` / `Explore` / `Worker`，见 `BuiltInSubagentName`）：模型派发 `subagent_type` 匹配、`setBuiltInModelOverride({ agentName })` 回写、`data-testid`、会话行标题与 `subagentType` 身份字段一律用英文，不做翻译。翻译只发生在两处纯展示层——设置页内置列表主名称与侧栏 tab 类型标签；两者共用同一张「内置名 → 显示文本」映射，不允许各写一份名字分支。
- 三个内置类型的中英文显示名对照：`general-purpose` → 通用 / general-purpose（英文界面保持与现状一致的原文，避免视觉变化），`Explore` → 探索 / Explore，`Worker` → 工人 / Worker。设置页搜索必须把本地化后的显示名拼进 haystack（否则中文名搜不到）；侧栏 tab 类型标签只进搜索索引、不上屏为主标题，会话行标题保持英文，不受「tab 标题与会话行标题逐字一致」约束影响（该约束只管 `title`，不管 `typeLabel`）。
- **设置里的模型覆盖与 Explore / 通用同一份内置覆盖表。** 选具体模型或组意图后必须能回填；存储导入必须把 Worker 当正式内置名保留。只拷 Explore / 通用会在下次读取时把工人覆盖清掉，界面会永远回到「继承默认」。
- **派出候选按父档硬过滤，不是只藏列表：**
  - 父为 Bare：可派 Worker 与用户 / 第三方自定义类型。Explore、通用硬拒绝（列表不出现，协议直连也拒绝，可见，与工具拒绝同类时间线）。
  - 父为 Ask / Plan / Agent：可派现有内置与自定义；Worker 硬拒绝。Agent 父自己就是可缓存的一把梭会话，不需要再挂 Worker。
- Bare 下派出未写类型 → Worker（与今天「未写则通用」同一习惯，只换缺省）。其它档未写类型仍是通用。
- 用户 / 第三方自定义类型在 Bare 下仍可派；工作档派出时锁死，不能像 Worker 那样中途切档。续跑若带切档字段 → 拒绝，不改档、不静默忽略。

### 调度默认

- Bare 秘书默认派 Worker。一条任务线 **可以** 开多个（并行、独立切片）；手册建议同一条线优先续跑，以免调查上下文作废。这是建议，不是硬上限。
- Worker **不能再派** 子代理。并行查阅由 Bare 秘书自己多开几个 Worker（通常都停在 Ask）。
- 调查走 Explore、改动走通用：这条默认策略 **只适用于非 Bare 父**。Bare 下由本文件替代。

### 工作档

- Worker 只有 Ask / Agent。禁止 Bare、禁止 Plan。
- 派出时由秘书填档（模型可见值为 Ask / Agent，内部仍是只读 / 完全访问）。第一次未填 → Ask。续跑未填 → 保持该 Worker 当前档。
- Ask ↔ Agent 都能切。只允许发生在 **两次前台执行之间**：派出那一次，或终态后的续跑那一次。对仍在运行的工人转向 / 入队不得改档；若续跑请求带了新档且目标仍在跑 → 拒绝改档（消息仍按既有转向 / 入队语义走，或整次拒绝——实现须选一种并在验收锁死；计划默认：**整次拒绝**，避免「话已入队、档已改、下一轮才生效」的错位）。
- 不另设「只改档、不带任务」的命令。档位只挂在派出与终态续跑上。
- 用户在子代理侧栏状态条能看到当前档（既有只读模式徽标，消费子快照）。不能点击切档。时间线卡片若展示类型，用 Worker / 工人，不要冒充 Explore 或通用。

### 系统说明与工具面（缓存不变量）

- 工具表从派出起固定为完整执行面（与主会话同类），用权限门而不是增删工具来区分 Ask / Agent。切档不增不减工具。计划类切档 / 提交工具仍从子面剔除（子没有独立计划恢复面）。派出类工具也不进 Worker（不能再派）。
- 系统说明走主会话通用前缀，**不**注入 Explore / 通用那种工种身份段。另有一段 **固定** 的通道说明：答复给调度者，用户看到的是父会话。这段不随 Ask / Agent 改写。
- 协作档说明在 Worker 内只交代 Ask 与 Agent（不要把 Plan / Bare 写进工人的行为段，以免它去当秘书或去交计划卡）。该段静态，切档只改请求尾部的短标签。
- 因此前缀能在同一 Worker 的 Ask → Agent（或反向）之间命中的条件是：同一子会话、同一工具表、同一系统说明、只追加消息与尾部标签。换类型、换工具面、换系统说明任何一项都会让调查缓存作废。

### 生命周期

- 仍是前台子代理：父回合等待终态；身份在派出时分配，终态可续跑；冷恢复、scope 校验、不可恢复 transcript 时的显式重置，沿用 [`subagent-foreground-only.md`](./subagent-foreground-only.md)。
- 停止条件与现有子代理相同：不按回合数硬掐（配置里若仍写着短上限，不得接上执行循环）。停靠窗口、用户 / 父取消、父回合结束，以及与现网一致的静默看门狗（约 10 分钟没有任何动静）。单条命令超时仍是工具级，不是整轮上限。
- 切档不是新开代理，也不是重置上下文。逻辑身份不变。只有既有的「transcript 不可恢复」路径才允许带重置标记的新上下文。

### 模型引导

- 官方 `bare` 技能 Index 改为：Bare 下默认派 Worker；派出时填档、建议先 Ask；同一线用身份续跑并可改档；Explore / 通用在 Bare 下不可用；自定义类型仅在确有特殊专长时用。
- 派出工具在 Bare 父下的类型列表与缺省说明必须与上条一致，避免技能写 Worker、工具描述仍在推销 Explore。

## 接口

- 派出：类型枚举增加 Worker；可选档位字段（Ask / Agent）。Bare 下缺省类型 Worker、缺省档 Ask。
- 续跑：可选档位字段。缺省保持。仅终态续跑接受该字段；目标不是 Worker 则拒绝该字段。
- 子快照 `config.mode` 随子档变化；侧栏状态条已按子快照只读展示，不新增第二条状态。
- 协作模式标签：Worker 请求尾部只允许 `<mode>Ask</mode>` / `<mode>Agent</mode>`。
- 拒绝：`ruleId` 与可见时间线与现有派出 / 权限拒绝同类。建议稳定码（实现时落到权限或工具拒绝，不混进 Goal ACK）：
  - 非 Bare 父派 Worker
  - Bare 父派 Explore / 通用
  - 对非 Worker 续跑带切档
  - 对运行中 Worker 带切档

## 不变量

- Worker 的档位真值只在子 runtime；父 Bare 不因工人切档而改档。
- 子工作档仍不得为 plan 或 bare。
- 只读父不得派出会变成 Agent 的工人；Ask / Plan 父派 Worker 直接拒绝（与「非 Bare 不能派 Worker」合并为同一道门即可）。
- 切档不改工具表、不改系统说明正文。
- Bare 父工具表仍不省略（秘书自己的前缀缓存规则不变）。
- 不得把 Worker 做成第二个顶层会话：无独立输入栏、不脱离父回合前台加入。
- `normalizeLegacyExecutionMode` 仍不产出 `bare`；Worker 缺省 Ask 不得被旧未知值收成完全访问之外的第三条迁移故事——派出缺省是新字段，不走那条历史归一。

## 验收

1. Bare 父未写类型派出 → Worker，档为 Ask；Ask 下写工具拒绝，读工具放行。
2. 同一 `agentId` 终态后续跑带 Agent → 同一子会话、同一工具表，写放行；前缀相对新开会话可复用（行为上：不新建身份、无重置标记、子快照档变为 Agent）。
3. 再续跑不带档 → 仍为 Agent。再带 Ask → 收回只读。
4. 对运行中 Worker 续跑带档 → 拒绝切档；正在跑的一轮档不变。
5. Agent / Ask / Plan 父派 Worker → 可见拒绝，无子 runtime。
6. Bare 父派 Explore 或通用 → 可见拒绝，无子 runtime。
7. Bare 父派自定义类型成功；对该身份续跑带档 → 拒绝，档不变。
8. Worker 终态结果仍带身份与子会话句柄；HistoryRead 能读完整 transcript。侧栏状态条显示当前 Ask / Agent，不可点。
9. Worker 不能派出子代理（派出类工具不在其工具面或调用拒绝）。
10. Bare 技能 Index 与派出工具描述不再把 Explore / 通用列为 Bare 默认路径。
11. `pnpm typecheck` / `pnpm lint` / `pnpm architecture:check --changed` 通过。

## 实现顺序

规格先于代码。本文件落定后按下列切片改，每片带测试，不把类型过滤、切档写入、提示词同一切片搅在一起。

1. **类型与门禁**：注册内置 Worker；按父档过滤可见类型与硬拒绝；Bare 缺省类型改为 Worker。不切档也能派一个 Ask 工人。
2. **通用上下文**：Worker 使用主会话通用前缀 + 固定通道说明 + 仅 Ask/Agent 的静态协作段；工具面完整且固定；去掉工种身份段。仍锁死派出时的档。
3. **切档**：派出 / 终态续跑带档；子 runtime 唯一写入；运行中带档拒绝；投影到子快照。非 Worker 带档拒绝。
4. **模型引导**：改 `bare` 技能与派出工具在 Bare 下的类型列表 / 缺省说明。
5. **展示**：确认侧栏状态条读到新档；类型名 Worker / 工人；设置内置项标明仅 Bare 可派。

## 范围外

- 不给 Worker 计划档、秘书档、计划卡。
- 不给用户点击切档，不给单独切档命令。
- 不让 Worker 再派子代理，不为 Bare 另开 Explore 口子。
- 不把跨会话的前缀缓存打通（做不到，也不该做）。
- 不改非 Bare 父的 Explore / 通用默认策略。
- 不把短回合上限接进执行循环。
- 不用 CDP 操作 YCode。

# Spec: 窄时间线收起次要元信息

## 目标

当会话内容区域较窄时，优先保留操作类型、文件名和耗时数值，收起重复或次要的信息，减少时间线摘要行的横向占用。

## 产品规则

1. 会话容器宽度不超过 480px 时，读取和编辑文件摘要隐藏文件名旁边的工作区路径，文件名仍保持可见。
2. 会话容器宽度不超过 480px 时，思考行和终端工具行的已完成耗时隐藏“耗时”措辞，只显示时间数值与单位；宽容器继续显示完整文案。
3. 运行中的“持续了”措辞不变；其他工具（例如等待剩余时间）的文案不受影响。
4. 文件路径仍保留在完整 title/悬停信息中；文件预览、编辑和耗时的计算口径均不改变。

## 状态所有者与接口

- `ToolLayout`、文件 renderer 与 `ReasoningTrigger` 继续拥有各自的展示结构。
- 纯展示格式由 `conversationDurationDisplay.ts` 提供完整耗时和紧凑耗时文案；不增加可变状态或协议字段。
- 响应式规则依据 `conversation` 容器宽度，而非整个窗口宽度，以适配桌面分栏和窄屏 Web。

## 验收场景

1. 会话容器宽度大于 480px：读/编辑行展示文件名与路径，思考/终端行展示“耗时 N 秒”。
2. 会话容器宽度不超过 480px：读/编辑行只展示文件名；已完成思考/终端耗时显示“N 秒”。
3. 窄屏运行中的思考行保留“持续了”措辞；task-output 等等待倒计时不变。
4. 收窄或放宽分栏时不改变数据、预览操作或耗时数值。

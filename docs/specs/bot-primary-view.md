# Spec: Bot 主视图（对人说话的岗位，不是第五档）

在外壳底栏增加第四档主视图 **Bot**。它不是 Plan / Ask / Agent / Bare 的第五档，也不是套在 Bare 上的皮肤。用户跟人设对象说话；对象没有项目文件工具、没有协作档。干活分两条：名下串行 **工人**（子代理），以及「任务」列表里异步跑的会话。Bot 可以新建任务、代用户向已有任务发话 / 停止 / 切档 / 答问 / 执行计划，并用 History 处理被中断的工人。

本文件是 Bot 产品规则的权威规格。父会话四档、秘书白名单仍以 [`bare-mode.md`](./bare-mode.md) 为准；工人切 Ask/Agent 以 [`bare-worker.md`](./bare-worker.md) 为准。外壳底栏既有三档以 [`workspace-shell-primary-tabs.md`](./workspace-shell-primary-tabs.md) 为准，本文件把它扩成四档主视图。点「谁在干活」打开侧栏看过程，对齐既有子代理目录侧栏，不另起一套过程 UI。

**状态：** 产品规则已齐，可按切片实现。尚未拆实现切片。

## 目标

- 底栏：任务 / 文件 / Bot / 设置，加「更多」。Bot 是主视图，不是下拉项。
- 人始终留在 Bot 对话。不因开工人或开任务被自动拽走。
- Bot 对人只通过受控出口说话：短消息气泡；需要拍板时才用带按钮的询问。模型自由正文不准进对话。
- Bot 不看、不改项目文件。简单调查派工人；大活或已有会话则操作任务列表里的会话。
- 单一实例：应用里只有一份 Bot 人设。人设、对话、记忆笔记都在应用里，不跟某个项目文件夹一起消失。
- 一个人一条永远往下的对话。太长了 Bot 自己压缩模型看到的那份；屏上旧气泡仍在。偏好和约定写进 Bot 自己的长期笔记，不指望压缩摘要代代相传。

```text
人在 Bot 页说话
  ├─ 发给你 / 带按钮询问 → 只进 Bot 对话气泡
  ├─ 简单调查 → 派出或续跑名下工人（串行，可切 Ask/Agent）
  │     状态条显示谁在跑、哪套模型
  │     点头像或名字 → 侧栏看该对象过程
  │     工人结束 → 状态指示立刻消失
  ├─ 新开或盯任务 → 任务列表里的会话（默认 Bare），异步不占工人那条串行位
  │     任务忙 → 代发工具报错；可停止、等待、订阅结束或等拍板
  └─ 人再说话 → 立刻中断当前工人占用；「停止」真停；新想法转向
        Bot 用 History 处理被停 / 被打断的工人
切到另一个 Bot → 这个人的工人继续跑，不占那个人的串行位
```

切档写入点：工人走子代理既有切档口；任务走该任务既有档位写入口。禁止把 Bot 自己写成 `bare` / `yolo` 等协作档。

## 产品规则

### 外壳与入口

- 主视图四档：`tasks` | `files` | `bots` | `settings`。底栏五格：任务、文件、Bot、设置、更多。
- 点 Bot：左栏为人设列表 + 置顶区，右栏为与当前 Bot 的对话。任务树保活不卸，规则同切文件 / 设置。
- 第一次进入且一个人都没有：立刻弹出创建对话框，不先给空页。关掉对话框则退回进入 Bot 之前的那一档主视图，不卡在空页。没有系统种下的默认人；拖文件夹、图、文件给谁，就是给谁。
- 删除只在该 Bot 的设置模态里。点删除 = **对用户隐藏**，不是从库里抹掉：人设、对话、笔记、它跟任务的创建关联都还在。名册和置顶不再出现；任务列表不再画出创建者小圆，关联记录仍在。不提供真删。一期不做找回。名册一个可见人都没有时，再弹创建，跟初次进入一样。

### 身份与岗位

- 创建必填：名字、头像、背景、当前工作区。创建时不配模型。
- 头像：产品用 emoji 选择器。本规格不规定选择器实现。
- **当前工作区这个值始终有。** 「不在项目里干活」本身也是一种工作区（与外壳无项目退化页同一类身份），不是空着不填。创建和设置里总要落在某一个上：当前已打开的项目，或这一档无项目。Bot 可以自己添加/打开项目，人也可以把文件夹拖给**任意**一个 Bot，由它去办加入；办完之后这个人的当前工作区就是那个项目。关了某个项目也不挡聊天；值还在，需要干活时 Bot 自己加回来或换成别的（包括换回无项目）。
- **不在程序里按岗位拦截路径**：Bare / Agent 任务本身权限就高，能看别的文件夹；收不收手靠系统说明和技能。
- 点右栏灵动岛**整颗胶囊**（头像或名字）打开设置模态。可改：名字、头像、背景、当前工作区、模型、思考档位；可勾选隐藏输入区模型选择器。
- 该勾选新建默认**勾上**：输入区不出现模型选择器，换模型去设置。
- Bot 的模型与思考档位只作用于 **Bot 自己这条对话**。工人用子代理设置里的模型和思考，不能从 Bot 对话或设置里改工人那份。

### 置顶

- 列表里的人和顶栏大头像是**同一入口的两种形态**，不会同时出现。
- 拖到顶栏：列表行消失，顶栏居中出现大头像。最多 **3** 个。
- 再拖第 4 个：松手弹回原处，顶栏不变。
- 大头像拖回列表：恢复普通行。置顶区内部也可以拖，只改这最多 3 个的左右顺序。
- 点顶栏或列表中的人：右边跟这个人聊。灵动岛显示当前这个人的头像和名字。
- 窗口很窄、左栏从侧面滑出来时：顶部仍是居中大头像，下面是普通人设行，和宽屏同一套，只是整体变窄。

### 右栏对话

- 没有整条顶栏。当前对象是顶部居中的胶囊（灵动岛）。
- 模型自由生成的长正文不得作为气泡出现。
- 「发给你」：提示按约 120 字来写，硬顶 1000 字。这是 Bot 对人的普通气泡。
- 带按钮询问：仅当需要人二选一或拍板时再用；平时只用短消息。外观是新的消息气泡，不复用现有「问你问题」卡。最多 **2** 个按钮，只能选一个。
- 屏上还有未点的询问时，人在输入框发了一句：这句当普通新输入（照例先打断工人）。大号选择气泡**动画收成**一枚较小的「未选择」气泡，不要硬切消失。未选择态仍能看出曾经问过、人没按按钮。
- Bot 可以问人简单问题（一问、少量按钮）。也可以**代用户**在任务里回答询问、执行计划（执行计划本身就是往任务发一条消息）。系统权限弹窗已禁用，不作为场景。
- Bot 可以改一条任务的工作档，四档都可以切：Plan / Ask / Agent / Bare。
- 人可以把文件夹、图、单文件拖进**整片右栏对话**（含输入区），也可以拖到**左栏头像**（列表行或置顶大头像）。拖到谁就交给谁：文件夹走添加/打开项目；图和文件进这一条对话，由 Bot 决定转给工人或任务。

### 两条干活线

**工人（每个 Bot 自己一条串行位）**

- 前期简单调查：派内置工人。可复用同一身份，也可新开。两次干活之间可切 Ask / Agent，规则对齐 [`bare-worker.md`](./bare-worker.md)。
- 不出现在「任务」列表。**同一个 Bot** 里工人与 Bot 自己串行、不能同时干活。两个 Bot 各有各的占线，互不抢。切到另一个人时，前一个工人继续跑。
- 输入框上方状态条只显示**当前正在看的这个人**占线的那一个及其模型：要么这个 Bot 在想 / 调工具 / 说话，要么它的工人在干活。点头像或文字打开侧栏，看的就是这个占线对象。结束：指示立刻消失。另一个人在跑工人，不出现在这个人的状态条上。
- 人在这个人的工人占线时发下一句：**任何一条**都先打断**这个人**的工人占用。没有停止按钮。打断之后由 Bot 读这句话和 History：人是要收工，就不要把工人拉起来；人是新想法，就转向同一条或另开。
- Bot 必须会用 History 看清被停止、被打断的工人再决定续跑还是收工。这块写入 Bot 专用技能，不进常驻系统说明。

**任务（异步）**

- 可以新建正儿八经的大任务，默认档 **Bare**，**标题由 Bot 起短名**，出现在「任务」列表里，和普通任务一样能被用户打开、续跑、改档。带一个**创建者标记**：标题旁一枚不可点的小圆，圆内是该 Bot 的 emoji，悬浮出名字。尺寸语言靠近现有分组紧凑圆，但不跟分组抢色、不可点。人设被隐藏后界面不再画这枚圆，库里的创建关联仍在。不要做成另一种任务功能。也可以代用户向已有任务发话、停止、切档、答问、执行计划。
- 用户提到「之前某条会话」时，走已有任务，不为此新开工人。
- 目标任务正在跑：代发工具必须报错，不能假装发出去。Bot 根据进展决定停止、等它跑完、或订阅事件。
- 可订阅：结束（完成 / 失败 / 被停止），以及任务在等你拍板（问你问题）。权限请求不是场景。
- 任务不占工人那条串行位。Bot 在工人空闲时仍可跟人说话、派工人、处理通知。
- 代发内容在任务时间线标明 **Bot 代你**，能看出来不是手打。

### 一条线、压缩、笔记

- 左栏只有「人」，没有「这个人的多段历史」。没有「新对话」按钮。
- 压缩是 Bot 的工具，它想收就收。压缩只改模型下一轮看得到的记录，**不删、不藏屏上气泡**；往上翻仍能加载更早的。用户不看到压缩过程。
- 长期笔记和人填的「背景」分开：背景是人对岗位的说明；笔记是 Bot 记下的偏好和约定。笔记是真值，压缩摘要不能替代它。
- 笔记不进设置页。落到用户找得到的固定位置（按人一份）；人找到了就能看、能改，改了下一轮按新内容走。不是秘密，只是产品默认不把编辑器摆出来。
- 闲置一段时间（约 15 分钟没聊也没干活）Bot 可以自己占线做家务：压缩当前上下文、把现状写入笔记。人正在看这个人时，输入框上方占线条要出现，能感觉到它在收拾；人在别的页完全无感——不响通知、不打未读。家务不是对人说话，不得因此往对话里塞短消息。

### 离开本页时怎么叫人

- 人停在任务 / 文件 / 设置（或窗口在后台）时：Bot 发来短消息，或它订阅的任务结束 / 等拍板 → **不切走当前主视图**。
- 左栏每个头像的未读点只表示**这个人**有未读。底栏 Bot 一格的点表示**还有任何一个人**有未读；所有人都没有未读时这一点才不出现。
- 切到某个人（右栏已经是他的对话）即清这个人的未读；底栏的点由是否还剩别人未读派生，不会因为进了 Bot 这一档就一次清光。
- 走系统通知；提示音复用既有「声音与提醒」通道，可在设置里改或关掉。前台也响、后台走系统通知不重复，规则对齐 [`sound-and-notification-settings.md`](./sound-and-notification-settings.md)。在该设置里为 Bot **另开行为行**：至少「Bot 来消息」单独一行；它订阅的任务结束 / 等拍板复用任务完成、等待输入那两行，不另拆。
- 点系统通知：进 Bot 页并打开这个人。不在没点的情况下把人从正在看的主视图拽走。

### 模型引导

- 官方 Bot 技能：受众是 Bot 模型。说明怎么当对人岗位、何时派工人、何时操作已有任务、忙线代发会报错、打断后怎么读 History、何时用短消息、何时用带按钮询问、何时压缩、怎么写笔记、闲置家务不要对人说话、工作区没了就自己加或等人把文件夹拖进来。
- 系统前缀不写手册正文（保前缀缓存）。Bot 对话的协作档标签不存在，不得打 `<mode>Bare</mode>`。

## 接口（计划）

- 外壳主视图枚举增加 `bots`。无项目时 Bot 仍可进（对话在应用里）。
- Web 地址栏：`/bots` 停在 Bot 档，`/bots/<id>` 停在这个人。刷新还在这儿。桌面不写地址栏，规则对齐 [`web-url-routing.md`](./web-url-routing.md) 的「桌面不受影响」。
- 派出工人：复用子代理派出 / 续跑 / 切档；父是 Bot 会话，不是 Bare 父。工人模型不走派出参数覆盖。每个 Bot 一条占线。
- 对人说话：独立「发给你」工具（长度门）+ 需要拍板时的询问工具。
- 对任务：代发、停止、切档、订阅结束与等拍板。目标忙则代发失败，可见错误回给 Bot，不进用户气泡当成功。
- History：Bot 可查工人与任务会话存档，规则对齐既有 History 三件套的只读语义。
- 压缩：Bot 可调用的工具，只收模型上下文。
- 笔记：Bot 可读写自己那份笔记；不走项目文件工具。
- 工作区：Bot 可添加/打开项目（人把文件夹拖进对话也走这条）。细则待钉。

## 不变量

- Bot 不是协作档，不能写进 `executionPermissionModeSchema`。
- Bot 工具面不含项目 Read / Write / Bash / Sandbox。添加工作区、压缩、笔记不是项目文件工具。
- 工人不进任务列表。
- 任务忙时代发必须失败。
- 置顶与列表互斥；置顶不超过 3。
- 工人的模型与思考只来自子代理设置。
- 单一实例，不为多窗口复制名册。
- 名册与对话不提供真删，只隐藏。
- 一个人一条对话线；压缩不抹屏上历史。
- 每个 Bot 自己一条工人串行位；切人不打断另一个人的工人。
- 离开本页的提醒不抢当前主视图。

## 待钉

无。

## 验收

1. 底栏四档主视图可切。无打开项目仍能进 Bot（对话在应用里）。
2. 创建后列表出现普通人设行；拖到顶栏则列表消失、顶栏居中大头像；拖回恢复行；第四个松手弹回。窄窗滑出的左栏同样是顶部大头像 + 下面小行。
3. 右栏无顶栏，胶囊显示当前人；点整颗胶囊打开设置；默认输入区无模型选择器。询问气泡最多两个按钮、单选；人改打字则大号选择收成较小的未选择气泡，有过渡。
4. Bot 对话看不到模型长正文；短消息进气泡；工人占线时状态条有对象与模型，点开侧栏为该对象过程；结束指示立刻没。切到另一个人，前一个工人继续跑。
5. 工人不在任务列表。新建任务默认 Bare。向忙着的任务代发失败。代发在任务时间线为 Bot 代你。任务行创建者是标题旁不可点的 emoji 小圆；人设隐藏后圆不画、关联仍在库里。
6. 工人占线时人发任何一条都先打断占用；无停止按钮。Bot 根据这句话决定收工还是转向。
7. 设置里删除只是隐藏。名册不再出现此人。不提供真删。
8. 一个人一条线。压缩不抹屏上气泡。笔记人默认看不见，落到找得到的位置。
9. 离开 Bot 页时短消息或订阅事件：未读点 + 系统通知 + 可关提示音，不抢当前主视图。
10. `pnpm typecheck` / `pnpm lint` / `pnpm architecture:check --changed` 在实现切片落地后通过。

## 范围外

- 群聊、多 Bot 同房说话。
- 空闲主动翻项目资料或对人插话（闲置家务只压缩和写笔记，不给人发短消息）。
- 跨频道同身份、Bot 自有云电脑。
- 把 Bot 做成 Bare 档或第五协作档。
- 多窗口各一份名册（产品是单一实例）。
- 用 CDP 操作 YCode。
- 人设模板市场、导出导入、图片头像：一期不做，身份上不挡以后加。

# 资源管理器窗口 UI 规范

## 行为

- Resources Manager 的系统窗口标题与窗口内标题使用同一条 `resourceManager.title` 本地化消息，并随主应用保存的语言偏好显示。
- 刷新间隔、磁盘 I/O 进程筛选和模块筛选均使用 UI 包统一的 Select 控件，保留既有选项、标签、测试标识及选择行为。
- CPU、内存、磁盘 I/O 三个页签都在窗口底部固定展示 macOS 活动监视器风格的资源概览栏，且概览栏位于滚动区域之外，切换页签时随页签切换显示。
- 概览栏统一为三栏结构：左栏是当前指标的关键数值，中栏是双线采样趋势图与图例，右栏是补充的计数或容量数值。
- CPU 页概览栏：整机 CPU、YCode CPU、空闲比例；趋势曲线为整机 CPU 与 YCode CPU；右侧为纳入快照的进程数和逻辑 CPU 数。
- 内存页概览栏：整机内存占用比例、YCode 内存占用字节、空闲内存字节；趋势曲线为整机内存占用比例与 YCode 内存占整机内存的比例，两条曲线共用 0–100% 纵轴；右侧为纳入快照的进程数和物理内存总量。
- 磁盘 I/O 页概览栏：读速率、写速率、操作速率；趋势曲线为读速率与写速率，纵轴按当前可见历史窗口的峰值自适应；右侧为累计逻辑读字节与累计逻辑写字节。速率与累计值沿用磁盘 I/O 页既有的口径和筛选条件。

## 状态所有者与边界

- 独立 renderer 的 `ZCodeIntlProvider` 读取已保存的语言偏好；Resources Manager UI 负责把解析后的标题写入当前文档标题，Electron 使用该标题显示原生窗口标题。
- 刷新间隔状态由 `ResourceManagerApp` 持有；磁盘 I/O 筛选状态由 `DiskIoTab` 持有；Select 仅呈现并发送用户选择，不建立第二份状态。
- 概览栏由 CPU/内存页的 `ResourceManagerApp` 与磁盘 I/O 页的 `DiskIoTab` 各自渲染，共享同一个只负责排版的 `ResourceManagerOverviewFooter` 组件；概览栏不持有任何指标状态，只接收当前快照与采样历史。
- CPU 与内存页的采样历史由 `ResourceManagerApp` 从现有快照更新，仅保留最近 60 个 renderer 内存样本；同一个样本同时携带 CPU 百分比与内存百分比，曲线分别呈现整机与 YCode。快照没有线程数及内核 user/system 拆分，因此界面不得显示或推导这些值。
- 磁盘 I/O 页的概览栏复用 `DiskIoTab` 已有的快照与历史样本，不额外轮询，也不建立第二份磁盘快照状态。
- 改动限于 UI 展示层和本地化，不改变 Main 的采样生命周期、快照接口或数据所有权。

## 验收

- 切换为中文或英文偏好后，Resources Manager 的窗口标题分别显示对应本地化文本。
- 三个选择器均通过项目 Select 组件渲染，仍能更新间隔或筛选结果，标签可访问且选项文案本地化。
- 概览栏固定在滚动区域之外，仅在当前页签显示；没有快照时使用占位状态，历史曲线在样本积累后绘制。
- 切换到内存页与磁盘 I/O 页时，底部概览栏分别展示内存占用与磁盘 I/O 速率趋势，数值口径与对应页签正文一致。

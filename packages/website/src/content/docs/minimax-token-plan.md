MiniMax Token Plan 是订阅制配额，与 MiniMax 开放平台的按量付费余额是两套互不相通的体系：配额接口只认订阅 Key。YCode 为它单列了一个模板——添加供应商时选 MiniMax Token Plan，填入**订阅 Key**（不是开放平台 API Key），查询用的就是这把 Key，不需要额外凭据。

## 看到什么

设置页的供应商卡片与聊天输入框的浮层里，显示两个窗口的剩余百分比与重置时间：**当前周期**与**周**。

- 不在套餐内的模型显示「不在套餐内」，而不是 100%。
- 填错 Key 时接口会拒绝，界面提示密钥无效，上一次成功读到的数字仍然保留。
- 清空该供应商的 Key 后不再发起查询，展示值也随之清除。

## 说明

本能力标记为 **Beta**：未经真实账号端到端验证（维护者没有 MiniMax 订阅账号）。Beta 标记只出现在添加供应商时的模板卡片上。

不是所有工作都需要立刻做：整理笔记、批量重命名、写一份过时文档的更新草稿……这些事「今天做」和「三小时后做」没有区别。闲时任务（Idle-time Tasks）把这类**可推迟的工作**丢进空闲算力队列，等系统有空闲算力时自动执行，不占用正常额度。

## 使用方式

创建闲时任务时给一段完整、自包含的任务描述。它不会立刻运行，而是先在队列里拿一个号；当服务器有空闲算力时，任务会在**无人值守**的状态下继续当前会话执行，完成后你可以在队列里看到结果。

## 与自动化任务的区别

|          | 闲时任务                   | [自动化任务](/docs/automations) |
| -------- | -------------------------- | ------------------------------- |
| 开始时间 | 无保证，由空闲算力决定     | 有明确的 cron / 延迟计划        |
| 执行环境 | 本会话的空闲时段，无人值守 | 按计划派发的独立运行            |
| 适合     | 能等、不着急的批量工作     | 必须准时跑的例行事务            |

## 注意

- 因为没有保证开始时间，任务提示词要把期望产出写完整——执行期间没有人可以回答它的问题。
- 队列位置与状态（排队中、已开始、已完成）可以在任务列表里查看；界面为闲时任务提供独立的视觉标识，与定时任务的绿色处理区分。
- 创建闲时任务会占用有限的免费排队名额；配额不足时会明确报错，而不是静默排队。

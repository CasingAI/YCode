上游的 Web 版只以命令行发行包的形式存在，桌面客户端里没有任何入口。YCode 把这一段补齐了：**Web 变成一个真正会被用起来的能力**——桌面端一键开启局域网访问，手机或电脑的浏览器直连桌面正在运行的 Host。

## 它是什么形态

- **同一工作区、同一会话**：浏览器连的是桌面 App 里正在运行的那个 Host——任务列表、会话内容与桌面天然一致，不是另起一套服务端。
- **不依赖外部中转**：不经过 relay、配对码或隧道，连接建立在你自己的局域网内。
- **窗口级服务**：一个桌面窗口一个远控服务，随窗口销毁而停止；不做「桌面关闭后仍可远控」。

## 开启方式

桌面侧边栏底部的「远程控制」入口 → 打开开关 → 弹窗展示 `http://<局域网IP>:<端口>/?token=<token>` 链接与二维码，手机扫码或电脑直接打开链接即可。入口图标变橙色表示已启用。

## 稳定性与鉴权

- **端口固定**：首次开启选定并落盘，之后不再变化；被占用时临时让位空闲端口但不覆盖落盘值。
- **Token 固定**：只有「重置 Token」会换；运行中重置会断开所有已连接设备、旧链接立即 401。
- **首次令牌访问后转长期 Cookie**（HttpOnly，一年期），之后无需再带 token；清除站点数据或重置 Token 后需重新打开有效链接。
- **重启自动恢复**：App 重启后按落盘的端口与 token 自动恢复监听，原链接直接可用。
- **断线重连**：保留页面、任务、草稿与导航状态；对有副作用的命令按 `commandId` 对账，而不是盲目重放。

## 两条实时链路

桌面本机是连续实时链路（直连进程）；手机等远端浏览器是可重放链路（快照 + 补洞）。改动了 stream、快照或重连逻辑时，两种语义都要验证——这是 YCode 远程能力的核心边界。

## 注意

- 未构建 Web 产物时开启远控会得到明确的构建提示（先 `pnpm --filter @zcode/web build` 并重启应用），App 不会崩溃。
- token 是可直接访问桌面 Host 的凭据：不要把带 token 的完整链接发给不信任的人；怀疑泄露就「重置 Token」。
- 远控通道自身不对远端暴露——远端无法关掉自己所在的开关。

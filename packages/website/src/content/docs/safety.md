自托管意味着安全边界由你自己掌握。YCode 的默认策略是：**危险能力默认关闭、写操作有审批、策略执行点开放给你**。

## 审批与确认

- 工具执行按权限模式把关：需要审批的操作会弹出确认（等待确认有统一的视觉处理），你放行才执行；权限请求也可以交给 [Hooks](/docs/hooks) 程序化处理（`PermissionRequest` 事件，可 allow / deny）。
- [计划模式](/docs/plan)下模型只读探索，提交计划后由你批准才转入执行；计划被拒绝时不会落成执行。
- 提示词提交前有 `UserPromptSubmit` 钩子，可以 `continue: false` 拦下不当输入。
- 工具执行前有 `PreToolUse` 钩子，可返回 `deny` 拦截危险操作（或以退出码 2 表达），拦截原因会记录在日志里。

## 默认关闭的重型能力

以下能力都**默认不启用**，需要你显式开启：

- **Browser Use / Computer Use**：浏览器与计算机自动化默认不进入工具面；共享的 node-repl 运行时也只在两者任一开启时注册。
- **动态工作流**：设置 → 实验功能中的开关控制（见[动态工作流](/docs/workflows)）。
- **配置文件 Hooks**：`hooks.enabled` 默认关闭。

## 工作区信任

工作区配置（`.zcode/config.json`、`.agents/mcp.json`）里声明的 MCP 服务器默认**受信任并自动连接**，工作区 Hooks 在 `enabled: true` 时无条件运行。这是协作便利与安全的权衡，请记住这条规则：**只打开你信任的工作区**；不信任的项目先读一遍它的 `.zcode/` 与 `.agents/` 声明。

## 数据边界

- 代码、构建流程、会话数据都在你自己的机器上；模型请求发往你配置的供应商端点。官方 Coding Plan 的转发边界见仓库 NOTICE.md。
- 手机远控的 token 是可直接访问桌面 Host 的凭据：走局域网、不加外部中转，泄露时用「重置 Token」一键作废。
- 密钥不写进会提交的配置文件，用环境变量或本地配置。

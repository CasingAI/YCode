「设置 → 键盘快捷键」集中管理客户端的全部快捷键：每个命令来自统一的命令表，支持搜索、编辑、清除、冲突检测与一键恢复默认。

## 你能做什么

- **搜索**：按命令名或组合键搜索定位。
- **编辑与录制**：点击绑定行进入录制态，按下新组合键即完成改绑；`Backspace` 清除绑定。
- **冲突检测**：把一个键绑给第二个命令时会被拦截提示，不产生同键双动作；重新启用被让出的命令前也会预检默认键冲突。
- **恢复默认**：单条命令可恢复默认，「全部恢复默认」清除所有覆盖。

## 保留型快捷键：停止生成

「停止生成」是一个特例：

- 固定使用默认 `Esc`（展示为 Esc 键帽），**不能改键、不能清除**，操作列是一个开关（Switch）。
- 关闭开关后停止快捷键失效（停止按钮仍然可用），重新打开后恢复 `Esc`。
- 重新打开时如果 `Esc` 已被同作用域其他命令占用，会提示冲突并保持关闭。

## 边界

- 快捷键命令属于 window 通道，录制态按 `Esc` 仍表示取消录制，不会把 `Esc` 录成普通命令的绑定。
- 对话框等浮层优先消费按键：被浮层消费的按键不会触发停止生成等底层命令。
- 旧版本遗留的非空「停止生成」覆盖不会作为自定义绑定生效，运行时按固定 `Esc` 解释。
